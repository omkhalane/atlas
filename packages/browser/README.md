# @atlas/browser

Browser automation harness, skill execution environment, and DOM interaction engine for Atlas.

## Overview

Provides headless and headful web interaction capabilities for agentic workflows, web scraping, and automated navigation.

## Features

- **Harness & Automation**: Playwright / CDP integration for web control.
- **Domain Skills**: Specialized web actions (search, navigation, extraction).
- **Session Manager**: Isolated browser contexts and proxy support.
