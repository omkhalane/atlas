Multi-language support and localization for Atlas.

## Translation System

### Framework

- **Library**: i18next
- **Storage**: JSON files per language
- **Management**: Crowdin (Phase 2+) or manual

### File Structure

```
locales/
├─ en.json
├─ de.json
├─ fr.json
├─ es.json
├─ ja.json
└─ zh-CN.json
```

### Translation File Format

```json
{
  "app": {
    "name": "Atlas",
    "tagline": "Autonomous agents at your fingertips"
  },
  "buttons": {
    "save": "Save",
    "cancel": "Cancel",
    "delete": "Delete"
  },
  "menus": {
    "file": {
      "label": "File",
      "new": "New"
    }
  },
  "errors": {
    "fileNotFound": "File not found: {{filename}}"
  }
}
```

## Localization

### UI Text

All user-facing text is translated:

- Button labels
- Menu items
- Tooltips
- Error messages
- Help text
- Dialog titles

### Not Translated (Phase 1)

- Code syntax
- Technical terms (unless context-specific)
- Keyboard shortcut names
- File names and paths

### Date/Time Formatting

```javascript
// Use locale-aware formatting
const date = new Date();
const formatted = date.toLocaleDateString("de-DE", {
  year: "numeric",
  month: "long",
  day: "numeric",
});
// Output: "2. August 2026" (German)
```

### Number Formatting

```javascript
// Locale-aware number formatting
const number = 1234.56;
const formatted = number.toLocaleString("de-DE");
// Output: "1.234,56" (German decimal)
```

## Right-to-Left (RTL) Support (Phase 2+)

### Languages

- Arabic (ar)
- Hebrew (he)
- Persian (fa)
- Urdu (ur)

### CSS Mirroring

```css
:dir(rtl) .sidebar {
  /* Layout flips for RTL */
  flex-direction: row-reverse;
  border-left: none;
  border-right: 1px solid var(--color-border);
}

:dir(rtl) .input {
  text-align: right;
  direction: rtl;
}
```

### Component Adaptation

- Sidebar on right side (RTL)
- Text alignment flips
- Icons/images orientation adjusts
- Layout direction reverses
- Padding/margins flip

## Pluralization

### Rules

Different languages have different pluralization rules:

```json
{
  "items": {
    "one": "{{count}} item",
    "other": "{{count}} items"
  },
  "items_de": {
    "one": "{{count}} Eintrag",
    "other": "{{count}} Einträge"
  }
}
```

### Usage

```javascript
i18n.t("items", { count: 1 }); // "1 item"
i18n.t("items", { count: 5 }); // "5 items"
```

## Context in Translations

### Disambiguate Meaning

```json
{
  "file_noun": "File",
  "file_verb": "File the document"
}
```

### Formal vs Informal (Phase 2+)

Some languages have formality levels:

```json
{
  "greeting_formal": "Guten Tag",
  "greeting_informal": "Hallo"
}
```

## Translation Keys

### Naming Convention

```
[module].[feature].[element]

Examples:
- chat.message.send
- files.browser.rename
- settings.appearance.theme
- errors.network.timeout
```

### Consistency

- Same action = same key across app
- Similar actions = similar keys
- Use hierarchical names

- Professional translation quality
- Cultural appropriateness

## Glossary

### Technical Terms

Terms that should be consistent:

```
- Agent → Agent (all languages)
- Browser → Browser / Navegador / ブラウザ
- Plugin → Plugin / Erweiterung / プラグイン
- File → File / Datei / ファイル
```

### Brand Terms

- Atlas: Not translated
- Agent: Kept as-is (technical term)
- MCP: Kept as-is (acronym)

## Testing Translations

### Translation Testing Checklist

- [ ] All strings translated
- [ ] No hardcoded English text
- [ ] Plural forms correct
- [ ] Date/time formatting correct
- [ ] Number formatting correct
- [ ] RTL layout (if applicable)
- [ ] Character rendering correct
- [ ] Font supports all characters
- [ ] Context menu text fits
- [ ] Error messages clear
- [ ] Help text complete

### Pseudo-Translation Testing

- Use mock language (QABCD) to find non-translated strings
- Check for layout issues with longer text
- Verify string substitution works

### User Testing

- Native speaker review
- Usability testing in target language
- Feedback collection

## Accessibility + i18n

- Screen reader language matches UI
- Spell-check language matches
- Keyboard layout matches language
- RTL text reads naturally
